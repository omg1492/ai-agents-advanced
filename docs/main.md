Tento notebook slouží na přípravu pokročilého kurzu AI aplikací ve formátu 10 večerních lekcí, denně, pod obu dvou týdnů, takže intenzivní kurz. Cílem je praktickým způsobem probrat pokročilejší koncepty za rámec úvodních školení a vytváření produkčních AI aplikací a jejich zavádění do organizace. Mezi pokrošilá témata patří určitě enterprise integrace a MCP, bezpečnost (identita, red teaming), tool use, code interpreter, agentic RAG, deep research, non-chat scénáře jako je autonomní zpracování událostí (například reakce na vznik objednávky), reasoning modely, observabilita, produkční škálovatelné nasazení v kontejnerech, měření kvality a evaluations včetně zpětné vazby uživatelů, dále agent paměť (přizpůsobitelnost agentů uživatelům), agentic UI (vytváření např. infografiky nakódováním HTML apod.). Určitě také multi-modalita, zejména real voice chat.

Každá lekce musí mít krátký teoretický úvod, pokročilou ukázku konceptu (jak to vypadá ve větším) a live-coding na společném projektu (může být v menším rozsahu, než ukázka). Lekce má 90 minut, takže typické rozložení ať je 15 minut vysvětlení tématu, 20 minut pokročilá ukázka,  50 minut live-coding, 5 minut rezerva.

Jednotlivá témata na sebe musí logicky navazovat a musí existovat společný live-coding projekt, který se postupně nabaluje a staví se na výsledcích z předchozího dne. Projekt musí celý dávat smysl end-to-end, nějaké kompletní řešení, které budeme postupně rozvíjet, obohacovat, zabezpečovat, následně škálovatelně a robustně nasazovat, monitorovat a řídit kvalitu a životní cyklus.

Pro live-coding uvažuji o tom, že všechno bude v Pythonu s využitím některého z frameworků - pravděpodobně LangGraph, protože LangChain nemám moc rád, ale zvažme i variantu přímějšího použití OpenAI SDK jako jsou Responses nebo agent service. Live-coding bude s využitím GitHub Copilotu, takže bude to trochu vibe coding. V rámci kurzu potřebuji tedy dobře připravenou dokonale popsanou architekturu, implementační kroky, časté chyby a připravené prompty, ať to dobře postupuje a neztrácíme se.

Jak získat architekturu apod.? Uvažuji, že ukázková část, která bude komplexnější, by byla nadmnožinou té live-coding, nějaké podobné nebo dokonce stejné téma, ale širší. Tím pádem bych ho měl připravené dopředu a zkušenosti z něj včetně častých chyb a koncepty bych přenesl do jednodušší live-coding verze určené pro přímou práci studentů.

Technologicky to musíme doladit, ale určitě Python, OpenAI modely přes API, buď OpenAI SDK nebo kombinace s LangGraph. Pokud databáze, tak uvažujme buď PostgreSQL (včetně pgvector pokud budeme dělat RAG) nebo Redis (s Search a JSON nadstavbami), Python package management s uv. V prvních lekcích běžíme v lokálu, ale pak nasazovat přes Docker image do Kubernetes, kde možná budeme potřebovat i nějaké frontování nebo event sourcing (Redis, RabbitMQ, Kafka, DAPR - uvidíme). Observabilita bude hlavně OpenTelemetry a k tomu nějaký jednoduchý backend typu .NET Aspire, ale možná něco s databází, musíme rozhodnout. Pravděpobně bude potřeba nějaký framework na bezpečnostní testování a nějaký framework na evaluace (LLM as judge, feedback uživatelů apod.). Pro některé scénáře autonomního zpracování bude potřeba orchestrátor, asi bych dal Temporal.
